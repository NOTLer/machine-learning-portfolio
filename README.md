# Machine Learning Portfolio

Это портфолио моих учебных проектов по машинному обучению. В нём представлены алгоритмы, реализованные вручную по формулам, а также через библиотеки (`scikit-learn`), с анализом качества и визуализацией результатов. Репозиторий демонстрирует практический опыт работы с моделями, данными и базовыми ML-процессами.

---

## 📂 Структура репозитория

- `decision_trees_forest/` — деревья решений и случайный лес, сравнение ручной реализации и библиотечной  
- `discriminant_analysis/` — дискриминантный анализ (DA) по формулам  
- `clustering/` — K-Means, агломеративная и спектральная кластеризация, эксперименты с разными датасетами  

---

## 🚀 Опыт и результаты

- Реализовал **классические алгоритмы ML вручную** и сравнивал их с библиотечными версиями  
- Проводил **кластеризацию и сегментацию данных** на различных наборах  
- Подготавливал данные: очистка, масштабирование, кодирование категорий, создание признаков  
- Оценивал качество моделей с помощью **train/test split, accuracy, precision, recall, F1**  
- Визуализировал данные и результаты моделей для лучшего понимания работы алгоритмов
